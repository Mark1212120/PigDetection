# 猪只目标检测代码运行说明

本机VSCode打开 `D:\Projects\Pig_Detection_test`，先激活环境：

```powershell
conda activate pigdet
python train.py
```

默认六模型各40轮、batch=4、seed=42，自动测试并绘图。所有新输出放入 `experiments/records/<批次号>/`，终端显示各阶段实时输出和报告路径。100轮服务器预算使用 `python train.py --profile server_100`，需要相应显存。

只查看完成结果：打开 `experiments/work_dirs/report/index.html`。只校验入口：`python train.py --check`。只重建已完成结果图表：`python tools/build_experiment_report.py`。

已有100轮服务器结果不等于默认40轮本机配置的成绩。程序不自动激活环境，不自动接着中断checkpoint训练。根入口先完成所有训练选权重，再测试所有模型，最后出表和绘图；任何阶段失败都不会标记整批完成。

详细数据与指标说明见实验手册和README。
